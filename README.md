# Abdullah Abdulwahab Portfolio

A single page portfolio for front-end developer Abdullah Abdulwahab.

## Features

- Sticky header with the name, section nav and a dark or light theme toggle
- Editorial hero with a big headline, two buttons and a CSS-only orbital visual
- About section with two paragraphs of copy
- Seventeen skill bars — thirteen scored (React, Vue, Nuxt, Tailwind, Firebase, Supabase, SEO …) that fill to their percentage when scrolled into view, plus four marked "learning"
- Responsive grid of six case study cards with tag chips
- "From GitHub" section showing eight repositories up front with a "Show 37 more" toggle for the remaining thirty-seven, each with live demo and source links
- Compact list of further repositories and a link to the full GitHub profile
- Timeline with three experience entries and a marked rail
- SEO and social metadata: description, canonical, Open Graph and Twitter card backed by a 1200×630 preview image
- Contact form that validates on submit and confirms without leaving the page
- Sections fade in on scroll, and prefers-reduced-motion disables every animation

## Running it

Open `index.html` in a browser. There is no build step and no dependencies to install.
